# Vivá Home | página da bio

Página de apresentação da Vivá Home para o link da bio do Instagram.

## Editar
Tudo fica em `index.html`. No início do arquivo há um bloco `CONFIG` com:
- `lojaOnline`: link do e-commerce (usado em "Ver loja online" e "Ver peça")
- `consultoras`: nomes e WhatsApp
- `mapa`: link do Google Maps

O endereço da loja está na seção "Onde estamos" (procure por `[ENDEREÇO DA LOJA]`).

Cada alteração enviada para o GitHub é publicada automaticamente pela Vercel.
